# ADR 0003 — Open-core boundary

Status: Accepted
Date: 2026-07-28

## Decision

Community includes complete packaging/evidence/assessment/remediation/dossier workflow. Enterprise, Cloud operations, private connectors and maintained regulatory content remain commercial boundaries behind public contracts.

## Consequences

- Community cannot be intentionally crippled.
- Basic rules pack is transparent, versioned and testable.
- Public-export gate rejects commercial directories/content.
- SAP work starts with canonical contracts and synthetic tests; private adapter remains outside public export.
