# OpenPPWR Community roadmap

Status: public roadmap; dates and priorities may change. This is not a commercial commitment.

## 1.0.0 — current release gate

- Complete synthetic ACME packaging-to-dossier workflow through real API, PostgreSQL, RLS, evidence jobs, assessment, remediation and audit verification.
- Reproducible EN, PL and DE browser journeys.
- Apache-2.0 Community export, immutable release container, dual SBOMs, security scans and self-hosted documentation.
- Human security, Polish product and German regulatory-wording reviews before publication.

## Post-release Community priorities

- Improve installation ergonomics and supported deployment profiles.
- Expand accessibility, localization quality and operator diagnostics.
- Harden upgrade, backup and restore automation through more independent environments.
- Evolve public API/SDK contracts from demonstrated Community consumers.

## Separate commercial scopes

Managed Cloud operations, production ERP/SAP connector implementations, maintained commercial Regulatory content and Enterprise identity/operations modules remain separate offerings. Community remains a useful end-to-end product, not an intentionally crippled shell.
